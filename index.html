So funktioniert diese Übungsprüfung

Zeitmessung je Teil

Jeder Prüfungsteil hat ein eigenes Zeitlimit, das automatisch herunterzählt — genau wie bei der echten telc-Prüfung. Die Zeit läuft auch nach einem Neuladen der Seite weiter.

Nur vorwärts

Ist ein Teil abgegeben, geht es direkt zum nächsten. Ein Zurückspringen ist nicht möglich, so wie im Prüfungssaal.

Gesperrter Auswertungsbogen

Die Lösungen bleiben verborgen, bis Sie alle Teile abgeschlossen und die Prüfung final beendet haben. Erst dann lässt sich die Auswertung freischalten.

Hörverstehen

Wo Audiodateien hinterlegt sind, werden sie abgespielt. Fehlt eine Datei, steht das vollständige Transkript zum Mitlesen bereit.

Für Betreiber dieser Seite

Alle Fragen liegen als einfache JSON-Dateien unter /data/ und lassen sich unabhängig vom Code aktualisieren. Details zum Datenformat und zur Bereitstellung auf GitHub Pages stehen in der README dieses Repositories.
